# CEO 실사용 테스트 체크리스트 — 베타 오픈 전 최종 확인

이 문서는 개발 용어 없이, **평소 업무하는 방식 그대로** 따라 하면서 확인하는 체크리스트입니다.
빠르게 눌러보고 끝내지 않아도 됩니다 — 하다가 "어? 이거 이상한데" 싶은 부분이 있으면 그게 가장 중요한 정보입니다.

**접속 주소**: https://jumunhanjang.vercel.app (실제 사장님 계정으로 로그인)

---

## 1. 주문을 등록한다

- [ ] `주문관리` 메뉴에서 새 주문을 하나 등록해본다(엑셀 업로드 또는 "주문 등록" 버튼으로 직접 등록 둘 다 해보면 더 좋음).
- [ ] 등록한 주문이 목록에 바로 보이는지 확인한다.

**여기서 볼 것**: 평소 엑셀 올리던 방식 그대로 올렸을 때 이상한 점이 있는지, 직접 등록할 때 입력 항목이 헷갈리지 않는지.

---

## 2. 같은 날짜 주문만 골라본다

- [ ] `배송관리` 메뉴로 이동해서 오늘 배송일 주문만 보이게 필터를 걸어본다.
- [ ] 어제/전체 등 다른 날짜로도 바꿔보고 원하는 주문이 정확히 나오는지 확인한다.

**여기서 볼 것**: 날짜를 고르는 방식이 직관적인지, "이게 오늘 배송 맞나?" 헷갈리는 부분이 있는지.

---

## 3. 지역/동을 확인한다

- [ ] 배송관리 화면 상단의 지역 필터에서 시/군/구 → 동 순서로 눌러본다.
- [ ] 특정 동만 골랐을 때 그 동 주문만 남는지 확인한다.

**여기서 볼 것**: 평소 "오늘 이 동네부터 돌아야지"라고 생각하는 순서와 이 필터 순서가 비슷한지.

---

## 4. 같은 아파트 주문이 묶여 보이는지 확인한다

- [ ] 배송관리 화면에서 같은 아파트/단지 주문이 여러 건 있으면 카드 형태로 묶여서 나타나는지 확인한다(카드에 아파트 이름과 건수가 표시됨).
- [ ] 묶여 보이지 않는 주문(개별 주문)도 평소처럼 목록에 그대로 있는지 확인한다.

**여기서 볼 것**: "이 단지끼리는 같이 배정해도 되겠다"는 실제 판단과 화면에 묶인 것이 일치하는지. 묶였는데 실제로는 다른 방향/다른 단지인 경우가 있으면 알려주세요 — 이게 가장 중요한 피드백입니다.

---

## 5. 한 건씩 기사 배정한다

- [ ] 묶이지 않은 개별 주문 하나를 골라 기사를 배정해본다(평소 하던 대로 주문 하나씩 보면서).
- [ ] 배정 후 화면에 바로 반영되는지 확인한다.

**여기서 볼 것**: 기사 배정에 걸리는 시간이 실제 업무에서 느껴질 만큼 답답한지(참고: 내부 측정으로는 4초 안팎).

---

## 6. 같은 그룹이면 한 번에 선택해서 배정한다

- [ ] 4번에서 확인한 아파트 묶음 카드에서 "이 그룹 N건 선택" 체크박스를 눌러본다.
- [ ] 화면 상단(또는 하단)에 선택된 건수가 나타나는지 확인한다.
- [ ] 기사를 고르고 "일괄 적용"을 눌러 한 번에 배정해본다.
- [ ] 그중 1건만 마음이 바뀌어 다른 기사로 개별 변경해본다(나머지 건들은 그대로 있는지 확인).

**여기서 볼 것**: "여러 건을 한 번에 선택해서 배정한다"는 이 흐름이 평소 업무보다 실제로 빠르고 편한지, 아니면 오히려 헷갈리는지.

---

## 7. 가방번호를 입력한다

- [ ] 배송건 하나에 가방번호를 입력해본다.
- [ ] 다른 화면 갔다가 돌아왔을 때 입력한 값이 그대로 남아있는지 확인한다.

---

## 8. 회수 여부를 바꾼다

- [ ] 가방 회수 여부(미회수 ↔ 회수완료)를 눌러서 바꿔본다.
- [ ] 같은 가방번호를 쓰는 다른 배송건이 있으면 자동으로 회수 처리되는 안내가 뜨는지 확인한다.

---

## 9. 새로고침해도 유지되는지 본다

- [ ] 위에서 바꾼 것들(기사 배정, 가방번호, 회수 여부, 지역/날짜 필터)을 다 해본 뒤 브라우저를 새로고침(F5)한다.
- [ ] 다른 메뉴(주문관리 등) 갔다가 다시 배송관리로 돌아와본다.
- [ ] 값이 사라지거나 이상하게 바뀌는 부분이 있는지 확인한다.

---

## 10. 실제 업무 기준으로 "여기 불편하다"를 찾는다

정해진 항목이 아니라, **평소라면 이렇게 안 할 텐데 싶은 부분**을 자유롭게 적어주세요.

예시 형식(길게 안 써도 됩니다):
> 지역필터는 괜찮음
> 그룹 선택은 처음엔 뭔지 몰랐는데 눌러보니 편함
> 기사 변경이 약간 느림
> 가방번호 입력 UI가 작아서 누르기 불편함

---

## 피드백 주시는 방법

스크린샷 + 한마디만 보내주셔도 됩니다. CPO가 받아서:
1. 버그인지
2. 화면/사용성 문제인지
3. 베타 오픈 전에 꼭 고쳐야 하는지(P0/P1)
4. 오픈 이후에 천천히 고쳐도 되는지(P2)

를 판단해서 다음 작업 지시로 이어갑니다.

---

## (참고용, 안 읽어도 됨) 이 체크리스트가 이미 확인한 것들

CTO가 자동화 테스트로 이미 100번 넘게 확인해 통과한 부분입니다 — 그래도 사람이 실제로 눌러봤을 때의 "느낌"은 자동화로 확인할 수 없어서 이 체크리스트가 필요합니다.

- 배송그룹 알고리즘(같은 단지는 묶고, 다른 단지/다른 동은 안 섞임) — 실데이터 기준 검증 완료
- 기사 배정/가방번호/새로고침 후 값 유지 — 자동화 회귀 104건 전부 통과
- 다른 사장님 계정과 데이터가 섞이지 않음(테넌트 격리)
- Production 배포 상태 정상
