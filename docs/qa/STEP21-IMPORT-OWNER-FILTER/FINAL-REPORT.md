## ② 원본 다운로드 버튼 미노출 — 원인 확인 (지시한 5단계 순서대로)

### 결론: **회귀가 아니다. `file_path = null`인 기존 import뿐이라 버튼이 없는 것이 정상이다.**

#### 1·2. 현재 import의 `file_path` 값과 업로드 시점

Production `imports` 전체 20건을 조회했다.

```
업로드시각(KST)     계정     file_path   파일명
2026-09-08 07:33   user2    null       주문한장_주문템플릿_2026-08-27.xlsx
2026-09-08 07:31   user2    null       스마트스토어_..._20260908_0723.xlsx
2026-09-08 07:24   user2    null       스마트스토어_..._20260907_0757.xlsx
...
2026-07-16 18:49   admin    null       crm_test.xlsx

file_path 있는 이력: 0건 / 20건
버킷 오브젝트: 0건
```

**STEP19 원본 보관 기능 배포 시각은 오늘 10:31 KST**(`c071bc2`)다.
가장 최근 업로드가 **07:33 KST** — 즉 **모든 이력이 기능 배포 이전 업로드**다.
원본이 애초에 저장된 적이 없으므로 내려줄 파일이 존재하지 않는다.

#### 3. `file_path`가 있는데 버튼이 안 나오는가 → 해당 없음
`file_path`가 있는 이력이 0건이라 이 경우 자체가 성립하지 않는다. 반대로 `file_path`가
있을 때 버튼이 나오는 것은 STEP19 E2E **T13(Admin 이력 화면에 '원본 다운로드' 링크가
보인다)** 이 매 회귀마다 확인하고 있고, 이번 회귀에서도 PASS다.

#### 4. Admin 권한/조건 때문에 숨겨지는가 → 아니다
Production 화면 HTML 실측:

| | Admin | 사장님(user2) |
|---|---|---|
| `원본 엑셀` 열 헤더 | **있음** | 없음(정상 — Admin 전용) |
| `미보관` 표시 | **있음** | 없음 |
| `원본 다운로드` 링크 | 없음 | 없음 |

Admin 화면에는 **열이 정상적으로 그려지고 각 행에 `미보관`이 표시**되고 있다.
즉 UI 조건은 의도대로 동작 중이며, 표시할 원본이 없을 뿐이다.

#### 5. Production에 현재 코드가 반영됐는가 → 반영됨
`x-vercel-id`의 함수 리전 `hnd1`, 화면 문구 `최대 200건 표시`(STEP19-B 이후 코드)로 확인.

### 그래서 어떻게 하면 버튼이 보이나
**user2가 다음에 엑셀을 한 번 업로드하면 그 건부터 `file_path`가 채워지고 버튼이 생긴다.**
과거 업로드는 원본 자체가 없어 소급 복구가 불가능하다(STEP19 리포트에 명시한 그대로다).

**수정한 코드 없음.** 지시대로 새로운 다운로드 구조를 만들지 않았다.

## ① Admin 계정 필터

Admin 화면 이력 카드 우측에 `계정 필터` 드롭다운(전체 계정 / user1 / user2 / …)을 추가했다.
정산 화면의 계정 필터와 같은 방식(쿼리스트링 `?owner=` + `router.push`)이라 새 상태 관리가
붙지 않는다.

- **권한 정책 변경 없음.** 필터는 표시 범위를 **좁히는 쪽으로만** 동작한다. 서버는 admin일
  때만 `owner` 값을 쓰고, 사장님 세션은 `?owner=`를 직접 붙여도 `ownerScopeFor`가 본인
  계정으로 고정한다.
- 필터를 걸면 `업로드한 계정` 열은 감춘다 — 한 계정만 보는 중에 같은 값이 모든 행에
  반복되는 열은 정보가 아니라 잡음이다(정산 화면과 같은 판단).
- 해당 계정 이력이 없으면 `{계정} 계정의 업로드 이력이 없습니다.`로 안내한다.
